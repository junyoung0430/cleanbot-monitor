# CleanBot Monitor 🧹🤖

청소로봇 여러 대의 상태를 한눈에 보고, 고장이 나기 전에 소모품 교체 시점을 알려 주는 **웹 대시보드**입니다.

> 개인 학습용 포트폴리오 프로젝트이며, 모든 데이터는 가상으로 만든 것입니다.

## 만든 이유
산업용 청소장비 회사가 현장에 여러 대의 청소로봇을 두고 운영한다면,
관리자는 "어떤 로봇이 지금 문제가 있는지", "언제 소모품을 바꿔야 하는지"를 빠르게 알아야 합니다.
이 문제를 웹 화면 하나로 해결해 보고 싶어서 만들었습니다.

## 주요 기능
| 기능 | 설명 |
|---|---|
| 상태 요약 | 전체 / 정상 / 주의 / 오류 로봇 수를 한눈에 표시 |
| 로봇 카드 | 배터리, 배터리 수명, 브러시 사용 시간, 모터 전류, 오류를 카드로 표시하고 상태를 색으로 구분 |
| 상태 필터 | 정상 / 주의 / 오류 로봇만 골라 보기 |
| 유지보수 알림 | 브러시 사용 시간, 배터리 수명 기준을 넘으면 교체·점검 알림 (간단한 예측 유지보수) |
| 배터리 그래프 | 카드를 누르면 그 로봇의 시간대별 배터리 변화를 그래프로 표시 |
| 오류 로그 분석 | 최근 7일 오류 코드별 발생 횟수 그래프 + 로봇별 오류 기록 표 |
| 반응형 | 휴대폰에서도 볼 수 있도록 화면 크기에 맞춰 배치 변경 |

## 사용 기술
- HTML, CSS (CSS Grid, Flexbox, 미디어쿼리)
- JavaScript (배열 filter / map / forEach, DOM 조작, 이벤트 처리)
- Chart.js (그래프 라이브러리)

## 상태 판단 규칙
- **오류**: 오류 코드가 있을 때
- **주의**: 배터리 20% 미만, 브러시 200시간 이상, 배터리 수명 80% 미만, 모터 전류 2.5A 초과 중 하나라도 해당할 때
- **정상**: 그 외

## 파일 구조
```
cleanbot-monitor/
├── index.html   # 화면 구조
├── style.css    # 디자인, 반응형
├── data.js      # 가상 로봇 데이터, 오류 로그
└── script.js    # 상태 판단, 알림, 그래프, 표 그리기
```

## 실행 방법
`index.html` 파일을 브라우저로 열면 바로 실행됩니다. (그래프는 인터넷 연결이 필요합니다.)

## 앞으로 개선하고 싶은 점
- Python으로 가상 데이터를 계속 만들어 DB에 저장하고, 화면이 자동으로 갱신되게 하기
- 기준값 대신 데이터의 추세를 보고 교체 시점을 예측하는 AI 모델 적용해 보기
